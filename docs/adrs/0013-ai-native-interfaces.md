# ADR-0013: AI-Native Interfaces — Stable Surface, Shared World Context, Measurable Runs

- Status: accepted
- Date: 2026-08-03

## Context

One of the engine's stated principles is AI-native development: an agent should
be able to observe, drive and evaluate a game, and generate assets for it that
belong together. Three separate things have to hold for that to work, and they
are easy to get wrong independently.

1. An agent writes code against the engine. If the public surface shifts without
   warning, generated code rots and the agent cannot tell which parts are safe.
2. Art, music and dialogue are generated by separate tools. Left to themselves
   they produce a sunny sprite, a dirge, and a sarcastic NPC for the same level.
3. An agent balancing or playtesting a game needs numbers out of a run, not
   screenshots to look at.

## Decision

**A declared stability boundary.** Everything re-exported through
`amigo_engine::prelude` is stable public API; breaking it requires a major
version bump. Items behind `#[doc(hidden)]`, and modules not in the prelude, are
internal. Feature-gated modules follow the same contract once enabled. The rule
is stated at the top of `crates/amigo_engine/src/lib.rs` so it is visible to
whoever — or whatever — is reading the crate.

**A shared world context.** `amigo_core::world_context::WorldContext` carries the
constraints that make independently generated assets cohere: palette, visual
style, mood, era, biome, music style. It is RON-serialisable and lives in game
data (`assets/worlds/<name>.ron`), so `amigo_artgen` and `amigo_audiogen` consume
one description rather than each being prompted separately.

**Metrics from headless runs.** `amigo_api::metrics` collects gameplay metrics
during simulation, exposed over JSON-RPC, so an agent can run a scenario headless
and read out what happened.

## Consequences

- The prelude becomes the API contract, which means additions to it are
  commitments. That is the intended friction.
- `WorldContext` is only as useful as the tools' willingness to read it: a
  generator that ignores it silently breaks coherence, and nothing enforces this
  at the type level.
- Metrics are engine-level counters. Anything game-specific has to be pushed in
  by game code; the engine cannot know what a game considers a win.
